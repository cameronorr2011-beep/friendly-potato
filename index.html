1. Limits and Continuity

Theorem (ε–δ definition). limx→a f(x) = L ⇔ for every ε > 0 there exists δ > 0 such that 0 < |x − a| < δ ⇒ |f(x) − L| < ε.

Squeeze theorem for evaluable indeterminate oscillation:

−|x³| ≤ x² sin(1/x) ≤ |x³|  ⇒  limx→0 x² sin(1/x) = 0

2. Differentiation

Definition. f′(a) = limh→0 [f(a+h) − f(a)]/h, when the limit exists.

Key rules in distributed form — product, quotient, chain:

  • (uv)′ = u′v + uv′
  • (u/v)′ = (u′v − uv′)/v²,  v ≠ 0
  • d/dx f(g(x)) = f′(g(x))·g′(x)
d/dx ln u = u′/u ;   d/dx au = au ln a · u′
