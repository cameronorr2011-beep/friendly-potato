MATH 41B · AP Calculus BC — Course Notes

Unit review summaries, theorem statements and worked problem sets.

1. Limits and Continuity

Theorem (ε–δ definition). limx→a f(x) = L ⇔ for every ε > 0 there exists δ > 0 such that 0 < |x − a| < δ ⇒ |f(x) − L| < ε.

Squeeze theorem for evaluable indeterminate oscillation:

−|x³| ≤ x² sin(1/x) ≤ |x³|  ⇒  limx→0 x² sin(1/x) = 0

2. Differentiation

Definition. f′(a) = limh→0 [f(a+h) − f(a)]/h, when the limit exists.

Key rules in distributed form — product, quotient, chain:

  • (uv)′ = u′v + uv′
  • (u/v)′ = (u′v − uv′)/v²,  v ≠ 0
  • d/dx f(g(x)) = f′(g(x))·g′(x)
d/dx ln u = u′/u ;   d/dx au = au ln a · u′

3. Integration

The Fundamental Theorem

FTC, part II. If f is continuous on [a, b] and F′ = f, then ∫ab f(x) dx = F(b) − F(a).
∫−∞∞ e−x² dx = √π

4. Infinite Series

Ratio test. For Σan with an ≠ 0, let ρ = limn→∞ |an+1 / an|. The series converges absolutely if ρ < 1 and diverges if ρ > 1.
